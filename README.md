# Human Emotions Detection Through Text

## Goal
To build a machine learning model that detects human emotions from text input using Natural Language Processing and classifies them into categories like happy, sad, angry, fear, surprise.

## Tools Used
Python, Pandas, Scikit-learn, NLTK, NLP, TF-IDF, Logistic Regression/SVM

## Key Insights
1. Preprocessed text data using NLP techniques like tokenization, stopword removal, and lemmatization
2. Converted text to numerical features using TF-IDF vectorization for model training
3. Trained classification models like Logistic Regression and SVM to detect emotions from sentences
4. Achieved good accuracy in classifying emotions and evaluated using confusion matrix and precision-recall

## Dataset
Used labeled text dataset with sentences annotated with emotion categories for supervised learning.
